The reconciled release-3.2 contract it implements, as a single left-to-right fold:

- **Source lifecycle first**: each record's source is trimmed of ASCII edge spaces only (`strip(" ")` — tabs are data), then looked up once in the exact, case-sensitive alias table (`core→platform`, `svc→service`, `web`/`ui→frontend`, `jobs`/`batch→worker`; unknowns kept, including the empty string). The bucket is created before any change is inspected, at first-canonical-appearance position, even for empty or rejected-only records.
- **Policy gate next**: `add`/`remove`/`adjust`/`hold` are accepted with multipliers 1/−1/1/0; `ignore`/`void` are rejected before any key or label work — no entry, occurrence, or label leakage, but the record's bucket survives.
- **Key identity**: ASCII edge trim → `casefold()` → one global alias lookup (`err`, `warn`, `lat`, `dur`, `cfg`) → one lookup in the table for the *canonical* source (`compile`/`compilation→build`, `request`/`req→requests`, `paint`/`draw→render`, `job`/`task→jobs`). No recursion, no source casefolding.
- **Arithmetic**: `total += delta * multiplier` (signed, arbitrary-precision integers, no clamping); `occurrences += 1` for every accepted change, including holds and zero deltas.
- **Labels**: only on the accepted path — edge trim, casefold, drop empties (a tab-only label survives as `"\t"`), append unseen canonical values in first-seen order per entry.
- **Output**: first-seen order at all three scopes (sources, entries, labels), updates in place, exact field sets (`source`/`entries`; `key`/`total`/`occurrences`/`labels`), no sorting, no dropped empty buckets.
