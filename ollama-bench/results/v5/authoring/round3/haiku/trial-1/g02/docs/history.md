# Naming history

Component names are aliases, not additional packages. For a release on or after an entry's effective month, replace its old name with its new name before looking in the catalog or lock snapshot. Apply dated aliases repeatedly so a two-stage rename reaches the current package. Before the effective month, the old spelling remains old; if it is not present in the snapshot, the plan is empty.

The archive is split by retention period because release engineers often inspect the recent and long-term records separately. Both files are one chronological history when loaded by the test support module. The records are intentionally not sorted by filename.
