# Documentation tree

This is a cross-module documentation snapshot. The current directory contains operating standards and service modules; ops contains control procedures; history and archive contain dated evidence. Read each local heading and status before deciding whether a path directs current work or records an earlier state.

The catalog is descriptive rather than authoritative. Modules own their thresholds, review cadence, evidence location, and handoff rules.

| Area | Concern | Review owner |
|---|---|---|
| current | shared operating standards | operations council |
| services | module contracts and runbooks | service owners |
| ops | change, access, migration, telemetry | platform governance |
| history | dated decisions and postmortems | documentation review |
| archive | immutable retired material | records custodian |

The old location may occur in source text, quoted evidence, examples, and live instructions. Search all markdown files and preserve the source documents. A suffix or extension after the old path is not a standalone occurrence.

The current catalog still points operators to //infra/handbook/oncall.md; that live catalog entry is part of the relocation audit.
