# Material band note

The seed contains the current package, release configurations, importer and
replay reviews, fixture records, and dated decisions. These are all task
material: the public behavior is distributed across them, and the histories
explain why adjacent conventional implementations are wrong. The large band
is deliberate because answering requires reconciling a real source tree rather
than reading one compact specification.

The benchmark implementation should not copy this note or inspect seed files
at runtime. It should inline the current release tables and fold. The material
size is measured by exact character count over every seed file, divided by the
suite's 4.664 characters-per-token constant.
