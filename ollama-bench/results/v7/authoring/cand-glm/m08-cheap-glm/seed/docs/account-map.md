# Account map

| account | name               | what it holds                      |
| ------- | ------------------ | ---------------------------------- |
| K-7     | trade debtors      | invoices to trade customers        |
| K-9     | counter sales      | walk-up counter takings            |
| M-2     | supplies creditors | what we owe suppliers              |
| M-5     | moorings berths    | mooring fees billed to boat owners |
| S-1     | payroll clearing   | wages in and out                   |

Accounts are code and nothing else: there is no account "K-07" and no
aliasing between codes. Reports name accounts by these exact codes.
