# Who does what

- **Compliance Review** - owns the reconciliation rules, the month-end
  procedure, and closes each month.
- **The counter drafter** (rota) - keys rows from the invoice folder and
  the till roll through the month.
- **Finance** - reads the balances, raises queries (the S-1 one in
  April, the K-7 one in October).
- **The depot counter** - counts shelves, feeds the stock system, and
  has nothing to do with the ledger CSVs.
- **IT** - owes the depot a scanner export since August; see incident/.

A query is answered from the ledger files by the rules, never from a
count sheet, a stock system figure or a memory of the counter.
