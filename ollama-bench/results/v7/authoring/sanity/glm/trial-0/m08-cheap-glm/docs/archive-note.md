# What is in this repository, and what is not

The repository holds the current books: July, August and September
2026, plus the rules and the paper trail. It deliberately holds
nothing else:

- **Prior-year ledgers** - archived offline after each year closes
  (history/CHANGELOG.md, 2026-06-30 entry). The archive is not here and
  nothing in the current files references rows in it; the OPENING rows
  carry the agreed figures instead.
- **Invoice folder and till rolls** - the physical sources rows are
  keyed from. They stay with the counter.
- **The stock system** - a separate system entirely. It does not share
  a database, a format or an owner with the ledger, and no file here
  imports from it.
- **Superseded rules** - none. The reconciliation rules have stood
  unchanged since the practice was set up (history/2026-02-01).

If a figure cannot be traced to the three CSVs by the rules, the answer
is that it does not exist here - not that it is in an archive.
