# Depot Friday checklist - Towpath counter

Pinned by the till. Initial each line; the sheet goes to the stockroom
lead with the count figures.

- [ ] till float counted and signed before opening
- [ ] shelves walked in inventory row order (file order = shelf order)
- [ ] every inbound crate since last Friday has a signed delivery note
- [ ] discrepancies of three units or more flagged to the lead, same
      morning
- [ ] scanner gun docked and syncing (if it is not, that is an IT
      ticket, not a note on the sheet)
- [ ] count sheet filed, initialed by the lead

The stock system is fed by this sheet. The ledger is not: ledger rows
come from the invoice folder and the till roll only (month-end
procedure, step 1).
