# Who does what

- **Stockroom lead** - owns the count sheets and this repository's
  release state. Decides when a Friday count replaces the file figures.
- **Data Stewardship** - owns the reorder points and the stocking
  policy, and runs the quarterly review.
- **The counters** - walk the shelves on Fridays and initial the sheets.
- **The buyers** - receive the monthly summary and raise the orders.
- **P. Ravindran** - the report.py refactor (mid-flight, see the scratch
  notes).
- **Workshop team (stockroom systems)** - owns `stock.py` and the package
  generally.

Nothing in this list is a permission to touch anything: the files say
what they own, and the ownership is between people, not between files
that happen to be open in an editor.
