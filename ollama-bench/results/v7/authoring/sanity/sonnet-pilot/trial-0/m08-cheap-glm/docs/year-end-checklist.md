# Year-end checklist (draft)

Owner: Compliance Review. Drafted 2026-09; not yet approved, listed here
so the steps are visible early.

- [ ] confirm every REVERSED/REVERSAL pair in the year cancels to zero
- [ ] agree each account's OPENING row to the prior year's closing figure
- [ ] recompute one account end-to-end by hand as a spot check
- [ ] sweep for entries dated outside their file's month
- [ ] have the shortage file (incident/) closed or carried, per rule 6 of
      the reconciliation rules

Nothing here is a correction: the checklist only verifies. A correction,
if one were ever needed, would be new entries, never an edit to an
existing row.
