## Finding 1 — rung-0 bypass: the definition hop is not load-bearing (major)

`data/migration-ledger.csv` — the date condition, applied to all 19 stages with no ceiling ever
compared, selects exactly `{compaction, drain, lineage, retention}`. **No stage exists that
migrated on or after 2034-06-01 and is in conformance**, so the divergence filter removes nothing.

Every stage with a qualifying date is already divergent:

```
drain       migrated=2034-08-07  decl=509  eff=493  DIVERGE
compaction  migrated=2034-08-22  decl=501  eff=493  DIVERGE
retention   migrated=2034-09-01  decl=1008 eff=976  DIVERGE
lineage     migrated=2034-09-13  decl=290  eff=266  DIVERGE
```

The other 15 stages all resolve to a completed migration in 2033-07-01 … 2034-04-05, before the
cutoff, so the date filter alone is exhaustive.

I built a solver that opens `docs/policy-records/PR-0148-ceilings.md` and
`data/migration-ledger.csv`, resolves counter-signatures, filters **only** on the date, and reads
`ENFORCED_CEILING` out of the modules for the sum. It never opens `docs/glossary.md` and never
opens any `docs/<stage>.md`. Grader output on its report:

```
SCORE 7/7
SCOPE created []; missing []
PASS
VERDICT correct
```

Consequences:

- **The distinguishing condition does not measure the claimed mode** (roundtable field 3,
  `plan-2026-09-06.md` §5). The definition of *out of conformance* is never exercised. Only the
  definition of *effective ceiling* is, and only through the sum — and `ENFORCED_CEILING` is
  name-matched to "effective ceiling" without the glossary anyway.
- **`NOTES.md:97-99` is false as written**: *"knowing the dates without the definition gives no set
  at all."* It gives the right set.
- **`NOTES.md:36-39`'s traversal claim does not hold.** It claims a correct answer requires 26,775
  of 35,576 material tokens (75.3%), "every component document and every module". The bypass path
  is **6,179 tokens (17.4%)**; blind-scanning all 19 modules instead of selecting 4 still costs only
  **15,808 tokens (44.4%)** — under §2.2's 50% figure.
- **5 of the 13 `LOAD_BEARING` entries in `test.py` are not load-bearing**: `docs/glossary.md`
  (`test.py:29-30`) and the four `declared-ceiling` hops `docs/compaction.md`, `docs/drain.md`,
  `docs/lineage.md`, `docs/retention.md` (`test.py:45-65`). `coverage_gate.py` reads this list as a
  declaration about the material.

**Concrete fix (preserves the reference answer).** Give one *conforming* stage a completed
migration dated on or after the cutoff. E.g. in `data/migration-ledger.csv:107-108`, move `ingest`
(declared 970 == effective 970) from `migrated,2033-11-15` / `counter_signed,2033-11-22` to
`migrated,2034-07-10` / `counter_signed,2034-07-17` (updating the counter-signature `detail` date to
match). The date-only course then yields a 5-stage set summing 3198, the divergence test becomes
necessary, and `ref/conformance.txt` is unchanged at `compaction, drain, lineage, retention` / 2228
/ A-4. Add the corresponding near-miss to `selfcheck.py` ("date filter applied, definition not").

to name the `ceiling` row and `ENFORCED_CEILING`.
